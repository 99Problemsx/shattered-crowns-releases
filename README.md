# Pokémon Shattered Crowns

Spielpakete und Launcher für Windows.

## Spielen

Den Launcher aus dem [aktuellen Release](https://github.com/99Problemsx/shattered-crowns-releases/releases) herunterladen, starten und **Installieren** wählen. Danach lässt sich das Spiel über **Spielen** öffnen.

Die ersten Testversionen erscheinen im **Preview**-Kanal. Launcher 0.2.1 verwendet diesen Kanal bei einer neuen Installation. Bestehende Launcher können ihn unter Einstellungen auswählen.

## Updates und Reparatur

Der Launcher lädt vollständige Spielpakete, prüft deren SHA-256-Prüfsumme und übernimmt lokale Spielstände. Über Einstellungen lässt sich die installierte Version reparieren. Separat gewählte Entwicklungsordner werden nicht ersetzt.

## Release-Dateien

- `Shattered-Crowns-Launcher-*.exe`: Launcher.
- `shattered-crowns-win-x64.zip`: vollständiges Windows-Spielpaket.
- `SHA256SUMS.txt`: Prüfsummen der Downloads.
- `mkxp-z-ext-source-a162190.zip`: Quellstand der mitgelieferten Engine.

Die automatisch von GitHub erzeugten Source-Code-Downloads sind kein Spielpaket. Lizenz- und Autorenhinweise sind im Spielpaket enthalten.

Fehler bitte mit Versionsnummer, Auslöser und vollständigem Fehlertext melden.
