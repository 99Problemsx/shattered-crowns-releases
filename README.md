# Pokemon Shattered Crowns — Releases

Public distribution repository for the Shattered Crowns game and launcher.

## Game updates

Create a GitHub Release and attach these two files:

- `shattered-crowns-win-x64.zip` — full Windows game, with Game.exe and Data at the ZIP root.
- `SHA256SUMS.txt` — SHA-256 checksum for that ZIP.

Use the game version as the release tag and write patchnotes in the release description. The launcher reads them automatically. Mark test builds as pre-releases; players receive them only on the Preview channel.

The game source archive generated by GitHub is not an installable game package.

## Launcher

The launcher supports installation, updates, repairs, progress and cancellation, offline play, and safe recovery from a failed installation. Releases are public and require no player GitHub account or token.

Development and editing tools remain in the development project.
